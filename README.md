# Portfolio Site

HTML/CSSで制作した個人ポートフォリオサイトです。

## 制作内容

自身の制作実績やスキルを紹介するためのWebサイトとして制作しました。

ABOUT、WORKS、SKILLS、CONTACTで構成し、
制作物をカード形式で掲載しています。

## 使用技術

- HTML
- CSS
- Flexbox
- Media Queries
- GitHub Pages

## 工夫した点

- 制作実績が分かりやすいカードレイアウト
- 余白を活かしたシンプルなデザイン
- グリーンをアクセントにした統一感のある配色
- スマートフォン向けのレスポンシブ対応
- PC・スマートフォンでの表示確認

## 掲載している制作物

- NAGOMI CAFE
- Matcha Wagashi Paper
- Japanese Food Cards
